# Практическое задание: Одномерные массивы в C#

## Студент

**ФИО:** Неделько Артемий  
**Группа:** ИС-3.2  
**Вариант:** 1

## Исходный репозиторий

https://github.com/zayarniy/arrays-practice

## Выполненные задания

- **Task1.Statistics** — статистика случайного массива.
- **Task2.InputSort** — ввод, разворот, сортировка и поиск минимума и максимума.
- **Task3.Unique** — получение массива уникальных элементов без LINQ и HashSet.
- **Task4.Exceptions** — обработка исключений при вводе данных и обращении к массиву.
- **Final.Task** — работа с массивом температур: среднее, минимум, максимум и количество дней с температурой выше 20 °C.

## Вариант 1

Для индивидуального задания использован массив температур. Программа вычисляет среднюю, минимальную и максимальную температуру, а также количество дней с температурой выше 20 °C.
